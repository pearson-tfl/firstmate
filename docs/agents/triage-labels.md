# Triage labels

Use these labels on the AHR tickets identified in [issue-tracker.md](issue-tracker.md).
The `firstmate-fork` label identifies fork work and accompanies the applicable triage state.

| Canonical triage role | AHR label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for agent implementation |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a triage role, use the corresponding AHR label.
Do not use the retired `loop:ready` or `decision` labels for new work.
Triage readiness does not grant merge or upstream-publication authority.
